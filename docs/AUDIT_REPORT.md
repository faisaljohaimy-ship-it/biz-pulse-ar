# تقرير إغلاق فجوات NEXIOS — 2026-07-15

## النتيجة

أُغلقت الفجوات البرمجية التي كانت تمنع تسليم نسخة قابلة للبناء: توحّد مدير
الحزم على npm، أصبح التثبيت النظيف قابلاً للتكرار، نجح فحص الأنواع والاختبارات
والبناء، واختفى ملف الفيديو المفقود وكل مراجع الأصول العامة المكسورة.

## ما أُغلق

- حماية جميع مسارات النظام الداخلية بجلسة Supabase وإعادة التوجيه إلى `/auth`.
- تحقق Bearer فعلي للملخص العاجل، مع RLS وحد الطلبات ومعالجة أخطاء الاستعلام.
- قصر مفاتيح الصوت المدفوعة على `admin` و`manager`.
- حد إساءة لنماذج العملاء، تجزئة مفتاح الحد، وإزالة عنوان المستلم الشخصي من الكود.
- إزالة تسجيل رمز إلغاء الاشتراك وإخفاء رسائل الأخطاء الداخلية في الإنتاج.
- إضافة CSP وHSTS وCOOP/CORP وبقية ترويسات المتصفح.
- استبدال حزمة XLSX ذات الثغرات ببديل محافظ على واجهة الاستيراد؛ تدقيق npm = صفر.
- إزالة SDK HeyGen المتقادم وإيقاف سكّ الرموز المدفوعة حتى تركيب LiveAvatar مدعوم.
- توحيد `app_role` على `admin | manager | member` مع migration لتصحيح `moderator`.
- جعل حالات التكاملات مشتقة من البيئة بدلاً من ادعاء اتصال ثابت، وإضافة اختبار Power BI فعلي.
- استعادة manifest وservice worker وsecurity.txt وsitemap والصور العامة.
- تثبيت ألوان المناطق الأربعة، 44 نقطة تفاعل، توهج المنطقة النشطة، والكرة الشفافة ثلاثية الأبعاد أعلى اليسار.
- توضيح أن مؤشرات الرسم بيانات تجريبية، وربط نقر أيقونة المنطقة بتغيير سياق العمل.
- جعل CI حاجزاً فعلياً: npm ci، lint، typecheck، Vitest، build، وE2E مشروط بأسرار صريحة لا بتجاوز أخضر.

## التحقق المحلي

- `npm run lint`: ناجح بلا نتائج.
- `npm run typecheck`: ناجح.
- `npm test`: جميع الاختبارات ناجحة.
- `npm run build`: ناجح ويولد مخرجات Cloudflare Workers.
- `npm audit --omit=dev`: صفر ثغرات منشورة.

## ما يبقى خارج الكود

لم يحدث نشر إنتاجي من مساحة المعالجة. يلزم تحديد حساب Cloudflare ومشروع Supabase،
إضافة الأسرار، تطبيق migrations، تشغيل E2E بحساب مخصص، ثم التحقق من العزل بين
مؤسستين والنسخ الاحتياطي والاستعادة. التفاصيل في `KNOWN_EXTERNAL_DEPENDENCIES.md`.
