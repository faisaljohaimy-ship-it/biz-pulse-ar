# دليل استخدام سَدِيد وFNN

سَدِيد يجمع متابعة الأمن الصناعي والصيانة والمؤشرات والتقارير في واجهة واحدة، ويساعد على فهم الحالة وتجهيز القرار. صلاحية الحساب ومصدر البيانات وحالة الاتصال تحدد ما يمكنك عرضه أو تنفيذه؛ وجود بطاقة أو زر لا يثبت أن الخدمة متصلة.

**الحالة الحالية:** الأتمتة والوكلاء والأدوات وسير العمل الآلي معطّلة أثناء الترحيل. استخدم القراءة المتاحة والتحليل اليدوي وتجهيز الخطط، ولا تعتبر الخطة أو الطلب إجراءً منفّذًا. هذا الدليل يشرح الوظائف الموجودة في الكود؛ توفرها في الموقع يحتاج نشر النسخة وإعداد الدخول والاتصالات واختبارها.

## ابدأ بحسب دورك

| المستخدم | البداية                                    | ما يتاح له                                                                                        |
| -------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| الزائر   | الرئيسية ثم خريطة النظام `/guide`          | استكشاف الوحدات والقراءات العامة المسموح بها، دون صلاحيات الموظف أو المالك.                       |
| الموظف   | تسجيل الدخول `/auth` بحسابه المعتمد        | العمل على البيانات والإجراءات التي تسمح بها عضويته وصلاحيته؛ الدخول وحده لا يمنح الإدارة.         |
| المالك   | الدخول بحساب المالك ثم بطاقة «سَدِيد وFNN» | فتح المحادثتين المستقلتين ومراجعة مساحة القيادة والأدوات وسجل النتائج، عندما ينجح التحقق الخادمي. |

إذا لم تظهر مساحة المالك، تحقّق من الحساب وإعداد صلاحياته؛ لا تستخدم حسابًا آخر ولا تُلغِ قيود الوصول لحل المشكلة.

## سَدِيد: القيادة والتحليل

افتح لوحة سَدِيد من بطاقته أو زر المساعد. اطلب سؤالًا محددًا عن البلاغات أو الصيانة أو المخاطر أو الامتثال، واذكر المنطقة والفترة عند الحاجة. أمثلة:

- «لخّص أوامر الصيانة المتأخرة في المنطقة الغربية، واذكر مصدر البيانات وتاريخها».
- «ما البيانات الناقصة قبل اتخاذ القرار في هذا البلاغ؟».
- «جهّز توصية متابعة، وافصل الحقائق عن المقترحات».

دور سَدِيد هو التحليل والتوجيه وتنسيق الوكلاء ومراجعة النتائج ضمن القدرات المتصلة فعليًا. التوصية تحتاج مراجعتك؛ لا تعني تشغيل وكيل أو تغيير حالة سجل تلقائيًا.

## FNN: مساحة المالك الهندسية

افتح «محادثة FNN» من بطاقة المالك أو أيقونته، أو انتقل إلى مساحة القيادة `/orchestration`. محادثته مستقلة عن محادثة سَدِيد.

اطلب خطة للأتمتة أو استيراد البيانات أو مراجعة البرمجة، مثل: «جهّز خطة لفحص ملف الصيانة ومعاينة التكرار قبل الرفع». FNN الحالي يجهّز الخطوات بطريقة حتمية؛ **لا يكتب في GitHub ولا يشغّل كودًا حرًا ولا ينشر الموقع بنفسه**.

يدعم محوّل التنفيذ القائم قراءة تشغيلية واقتراح بلاغ واقتراح تحديث أمر عمل، لكن الأدوات المعطّلة لا تنفّذ. أي تفعيل لاحق يتطلب صلاحية واعتمادًا واختبارات؛ وفي الحالة الحالية تبقى الطلبات خططًا للمراجعة. راقب حالة المهمة ومعرّفها ونتيجتها بدل الاكتفاء برسالة الإرسال.

## متابعة الصيانة

1. افتح «الأصول والمعدات» ثم صفحة الصيانة `/sec/maintenance`.
2. راجع المؤشرات وتاريخ المصدر، ثم تبويبات النشطة والسجل والتحليلات ومن البلاغات. استخدم الفلاتر للوصول إلى الأمر المطلوب.
3. افتح بطاقة الأمر لمراجعة حالته ومراحله والإجراء التالي. عند اتصال البيانات الحية، تظهر الإجراءات المسموح بها لحسابك؛ راجع التفاصيل قبل اعتماد أي تغيير، ثم تحقّق من الحالة المسجّلة بعده.
4. إذا ظهر تنبيه «القاعدة الحية لا تجيب»، فالمعروض نسخة تصدير مؤرخة، وليس تحديثًا آنيًا. لا تعتمدها لإثبات اكتمال تغيير جديد؛ أعد المحاولة أو ارجع للمسؤول.

القراءة العامة للصيانة محددة المدة والصلاحية، وتحجب البيانات الشخصية. ظهور بيانات تشغيلية للزائر لا يمنحه حق تعديلها.

## الملفات والتقارير ومصدر الحقيقة

في مركز رفع المعرفة `/knowledge-upload`، اختر ملفًا مدعومًا ثم افحص المعاينة والحقول والتكرار قبل اعتماد الرفع. **المعاينة ليست استيرادًا**، واستيراد المعرفة لا يعني حقن الملف تلقائيًا في جميع جداول التشغيل. تابع نتيجة المعالجة بعد الاعتماد.

افتح التقارير `/sec/reports` لمراجعة ما يتاح لحسابك، واستخدم أزرار التصدير الموجودة في الصفحة. راجع الفترة والمنطقة والمصدر قبل مشاركة التقرير.

| ما يظهر أمامك               | كيف تقرؤه                                                        |
| --------------------------- | ---------------------------------------------------------------- |
| بيانات من القاعدة           | قراءة وصلت من المصدر؛ راجع وقت التحديث ونطاقها.                  |
| تصدير أو نسخة مؤرخة         | بيانات محفوظة حتى التاريخ المعروض، وليست حالة لحظية.             |
| بيانات مرجعية أو عرض توضيحي | ليست دليلًا على تشغيل فعلي أو حالة إنتاجية.                      |
| «لم يُقَس»                  | لا يوجد قياس صالح؛ لا تعني صفرًا أو سلامة الحالة.                |
| تعذّر التحميل أو التحقق     | الخدمة لم تُثبت النتيجة؛ أعد المحاولة ولا تستنتج عدم وجود سجلات. |
| خطة أو بانتظار الاعتماد     | اقتراح لم يكتمل تنفيذه.                                          |

عند التعطل، سجّل اسم الصفحة ووقت المشكلة ومعرّف المهمة إن ظهر، وأرسلها للمسؤول دون كلمة المرور أو رموز الدخول أو المفاتيح. لا تستخدم النظام بديلًا عن إجراءات الطوارئ الميدانية المعتمدة.
