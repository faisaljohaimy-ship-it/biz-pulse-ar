# End-User Handbook

Welcome to Nexus — your executive command surface.

## Sign in
Email/password or Google. First sign-in seeds your personal executive dataset automatically.

## Core surfaces
| Route | What you'll do here |
|---|---|
| `/dashboard` | Daily executive overview |
| `/briefing` | AI-generated daily briefing with actions, risks, opportunities |
| `/boardroom` | Strategic KPIs + predictions panel |
| `/digital-twin` | Live operating-model view of the enterprise |
| `/fabric` | Intelligence Fabric: signals, alerts, sources |
| `/decisions` | Pending and historical decisions |
| `/memory` | Your institutional memory (commitments, recommendations) |
| `/forgotten` | Items silent too long — recover or close them |
| `/risk`, `/crisis`, `/cockpit` | Risk and crisis cockpit |
| `/intelligence` | Cross-domain intelligence stream |
| `/chief-of-staff` | Synthesised exec summary |
| `/governance`, `/transformation`, `/outcomes` | Enterprise programs |
| `/observability` | Audit + AI usage (admin) |

## ARIA Copilot
Click the chat icon or open `/assistant`. Supports Arabic and English, streaming, and pulls live context from your Fabric.

## Voice
`/voice` — speak to ARIA (STT) and have it read replies aloud (TTS), Arabic + English.

## Shortcuts
- `⌘K` — command palette
- `⌘/` — toggle locale (AR/EN)

## Privacy
All data is scoped to your account by Row-Level Security. Admins can audit usage but not impersonate.
