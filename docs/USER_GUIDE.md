# SADEED user guide

Open **Account menu → How to use SADEED**, or visit `/guide`, for the current in-app quick start.

The maintained Arabic handbook is [دليل استخدام سَدِيد وFNN](SADEED_USER_GUIDE_AR.md). It explains visitor, employee and owner access, maintenance workflows, SADEED analysis, FNN engineering plans, data sources and result verification.

Authentication methods depend on the deployed environment. FNN is restricted to the server-verified owner; opening a chat does not activate tools or execute tasks.
