# توليد صوت سَدِيد لفيديو الترحيب — وصفة خطوة واحدة

هذه الوصفة تُنفَّذ في جلسة تملك أحد المسارين: مفتاح `ELEVENLABS_API_KEY`
(مسار curl) أو موافقة أداة MCP `mcp__ElevenLabs__text_to_speech`.
لا اجتهاد مطلوب — كل قيمة أدناه منسوخة من مصدر الحقيقة في المشروع.

## ١) الإعدادات القانونية (من `src/lib/sadeed/voice-config.ts`)

| الإعداد                      | القيمة                                          | المصدر                               |
| ---------------------------- | ----------------------------------------------- | ------------------------------------ |
| Voice ID (صوت سَدِيد الحصري) | `izhopdR43PRI5gAmjXTj`                          | `SADEED_ELEVENLABS_VOICE_ID`         |
| Model                        | `eleven_multilingual_v2`                        | `SADEED_ELEVENLABS_MODEL`            |
| stability                    | `0.62`                                          | `SADEED_ELEVENLABS_VOICE_SETTINGS`   |
| similarity_boost             | `0.85`                                          | ↑                                    |
| style                        | `0.2`                                           | ↑                                    |
| use_speaker_boost            | `true`                                          | ↑                                    |
| speed                        | `0.9` (تمهّل مقصود — بند «عدم السرعة في النطق») | ↑                                    |
| output_format                | `mp3_44100_128`                                 | نفس صيغة `/api/sadeed/tts` الإنتاجية |

**ممنوع** أي صوت آخر أو مزوّد آخر أو `speechSynthesis`. سَدِيد لا يرسل
`voiceId` بديلًا أبدًا.

## ٢) المسار أ — curl (نفس نداء الخادم الإنتاجي حرفيًّا)

```bash
# SCRIPT_TEXT = نصّ الفيديو بعد تطبيع النطق (القسم ٤ أدناه)
export SCRIPT_TEXT='...النص المطبَّع هنا...'

curl -sS -X POST \
  "https://api.elevenlabs.io/v1/text-to-speech/izhopdR43PRI5gAmjXTj/stream?output_format=mp3_44100_128" \
  -H "xi-api-key: $ELEVENLABS_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Accept: audio/mpeg" \
  -d @- <<JSON > sadeed.mp3
{
  "text": $(printf '%s' "$SCRIPT_TEXT" | python3 -c 'import json,sys; print(json.dumps(sys.stdin.read()))'),
  "model_id": "eleven_multilingual_v2",
  "voice_settings": {
    "stability": 0.62,
    "similarity_boost": 0.85,
    "style": 0.2,
    "use_speaker_boost": true,
    "speed": 0.9
  }
}
JSON

# تحقّق فوري: يجب أن يكون الملف MPEG audio لا JSON خطأ
file sadeed.mp3 && ffprobe -v error -show_entries format=duration -of csv=p=0 sadeed.mp3
```

## ٣) المسار ب — أداة MCP (بديل مكافئ)

نداء `mcp__ElevenLabs__text_to_speech` بهذه المعاملات حرفيًّا
(الأداة تعيد رابط تنزيل قصير الأجل — نزّله باسم `sadeed.mp3`):

```json
{
  "text": "<SCRIPT_TEXT بعد التطبيع>",
  "voice_id": "izhopdR43PRI5gAmjXTj",
  "model_id": "eleven_multilingual_v2",
  "output_format": "mp3_44100_128",
  "body": {
    "voice_settings": {
      "stability": 0.62,
      "similarity_boost": 0.85,
      "style": 0.2,
      "use_speaker_boost": true,
      "speed": 0.9
    }
  }
}
```

ملاحظة: حقول الأداة العلوية لا تشمل `voice_settings`، لذا تُمرَّر عبر
`body` (بوابة التمرير الخام الموثّقة في مخطط الأداة). لا تعتمد على
الصوت الافتراضي للأداة — مرّر `voice_id` صراحةً.

## ٤) ثم التركيب

```bash
bash scripts/sadeed-video.sh swap-voice sadeed.mp3
```

السكربت يحاذي بداية الصوت إلى **2.236s**، ويطبّق fade in/out ‏50ms،
ويفحص بوابة المدة (القسم ٦) قبل أي كتابة.

## ٥) نصّ الفيديو

> **يُلصق هنا من المالك — هو من كتبه في HeyGen.**

**وصل من المالك ٢٠٢٦/٠٨/١١:**

```text
سديد — الذكاءُ التنفيذيُّ للأمنِ الصناعي.
أُتابعُ المواقعَ والتصاريحَ والامتثالَ لحظياً — ولا أُجيبُ إلا بدليل.
اسألني… وسأُجيبُكَ إجابةً سديدة.
```

> ⚠ تقدير المدة المنطوقة لهذا النصّ ~١٢–١٦ ثانية عند speed 0.9 —
> والهدف ٤٨٫٣ ± ١٫٠ ثانية، فبوابة 🛑 **ستتوقّف** وتطلب قرار المالك:
> قصّ الفيديو / إبقاء بقية الفيديو صامتة / نصّ أطول.

```text
(فارغ — بانتظار نصّ المالك)
```

### تطبيع النطق قبل اللصق (وفق مهارة `aria-pronunciation` — المادة ٢٢ §٥)

النص يُرسل إلى ElevenLabs مباشرة، فلا يمرّ على حارس
`applySadeedPronunciation` في العميل — **التطبيع يُطبَّق يدويًّا على النص
الملصوق نفسه**:

1. **الفواصل «·» تُكتب «و»** — رمز الفصل البصري لا يُنطق.
2. **الأرقام تُكتب حروفًا عربية** (نمط `arabicCardinal`، يغطي ٠–٩٩):
   «18» ← «ثمانية عشر»، «7» ← «سبعة».
3. **الاختصارات اللاتينية تُكتب بمنطوقها العربي** — لا تُترك لتُتهجّى
   حرفًا حرفًا:
   - `SEC-18` ← «سِك ثمانية عشر» · `SAF-07` ← «ساف سبعة»
   - `PTW` ← «تصريح العمل»
   - `HCIS` ← «الهيئة العليا للأمن الصناعي»
   - `CCTV` ← «كاميرات المراقبة»
   - `SADEED` ← «سَدِيد»
4. **الأسماء المسحوبة لا تصل إلى مكبّر الصوت**: إن ورد `FINN` في نصّ قديم
   يُكتب «سَدِيد»، و`NEXIOS` يُكتب «المنصة». لا يُنطق اسم قديم أبدًا.
5. **المساعد مذكّر نحويًّا**: «سَدِيد لا يتعطل»، «سَدِيد نفسه» — لا صيغة
   مؤنثة.
6. النثر العربي السليم يُترك كما هو — التطبيع يمسّ الرموز والأرقام
   واللاتيني فقط.

## ٦) 🛑 تنبيه المدة — بوابة إلزامية

- الكلام الأصلي في الفيديو: **أول كلمة 2.236s → آخر كلمة 50.558s
  = ‏≈48.3s** ضمن فيديو 52.0s (الخريطة الكاملة: `voice/speech-map.json`).
- صوت سَدِيد المولَّد يجب أن تكون مدته **48.3s ± 1.0s**. إن خرج عن ذلك
  توقّف `swap-voice` بذاته وطبع «🛑 عدم تطابق: فرق Xs» — **لا مطّ ولا قصّ
  ولا تغيير speed للالتفاف** (السرعة 0.9 ثابتة دستوريًّا).
- عند فشل البوابة: عدّل **النص** (اختصارًا أو إطالة طبيعية) وأعد التوليد،
  ثم أعد `swap-voice`. قِس قبل التركيب:
  `ffprobe -v error -show_entries format=duration -of csv=p=0 sadeed.mp3`
- إيقاع مفيد للصياغة: الأصل جملة افتتاحية قصيرة (≈1.8s) ثم وقفة ≈1.3s ثم
  متن متصل ≈41s ثم خاتمتان قصيرتان. نصّ بهذا الإيقاع يهبط قرب 48.3s
  تلقائيًّا بسرعة 0.9.
