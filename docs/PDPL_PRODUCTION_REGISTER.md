# سجل الإطلاق الإنتاجي — PDPL

هذا السجل هو نقطة التحكم التنفيذية للامتثال العام في NEXIOS AI OS. لا يضع
بيانات قانونية افتراضية، ولا يسمح لتقرير الجاهزية بإعلان **Release Candidate**
ما لم يزوّد مالك المنصة القيم الفعلية ويعتمدها المستشار القانوني.

## ضوابط إلزامية قبل النشر

| الضابط                      | متغير النشر                       | معيار القبول                    |
| --------------------------- | --------------------------------- | ------------------------------- |
| اسم المتحكم                 | `PDPL_CONTROLLER_NAME`            | الاسم القانوني الفعلي           |
| السجل/الترخيص               | `PDPL_CONTROLLER_REGISTRATION`    | مرجع قابل للتحقق                |
| مسؤول حماية البيانات        | `PDPL_DPO_NAME`                   | اسم الشخص أو الوظيفة المعتمدة   |
| قناة حقوق أصحاب البيانات    | `PDPL_PRIVACY_CONTACT_EMAIL`      | بريد صالح ومراقب                |
| منطقة استضافة البيانات      | `PDPL_DATA_REGION`                | المنطقة الفعلية من لوحة المزوّد |
| اتفاقيات المعالجة           | `PDPL_DPA_REGISTER_STATUS`        | `approved` أو `executed` فقط    |
| إتلاف الحساب بعد الطلب      | `PDPL_ACCOUNT_ERASURE_DAYS`       | 1–3650 يوماً بقرار قانوني       |
| الاحتفاظ بسجلات التدقيق     | `PDPL_AUDIT_RETENTION_DAYS`       | 1–3650 يوماً بقرار قانوني       |
| الاحتفاظ بالسجلات التشغيلية | `PDPL_OPERATIONAL_RETENTION_DAYS` | 1–3650 يوماً بقرار قانوني       |
| مسؤول حادثة التسريب         | `PDPL_BREACH_OWNER`               | مالك مناوبة قابل للتصعيد        |
| مرجع الاعتماد القانوني      | `PDPL_LEGAL_APPROVAL_REF`         | رقم مذكرة/تذكرة اعتماد          |

القيم سرية تشغيلية، لذلك لا يعرض تقرير الجاهزية محتواها؛ يعرض فقط
`configured` أو حالة فشل. ولا تشمل هذه المصفوفة أي تغيير على منصة الحج أو
سياساتها، التزاماً بنطاق الإصدار الحالي.

## سجل المعالجات الفرعية

تُراجع الاتفاقية، موقع المعالجة، الحذف، نقل البيانات، والإخطار بالحوادث لكل
مزود مُفعّل فعلياً: Supabase، مزود النموذج اللغوي المختار، ElevenLabs، Microsoft،
Resend، Twilio، وStripe. لا يكفي وجود مفتاح API؛ يجب أن تكون حالة السجل
`approved` أو `executed` وأن يشير `PDPL_LEGAL_APPROVAL_REF` إلى قرار المراجعة.

## بوابة الإصدار

المسار الداخلي `/readiness` يحتسب بعداً مستقلاً باسم **PDPL Compliance**.
أي قيمة مفقودة أو غير صالحة تظهر كعائق إنتاجي وتمنع `release_candidate=true`.
