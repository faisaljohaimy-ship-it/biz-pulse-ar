# وحدتا HCIS و PTW — دليل مبسّط

منتجان متخصّصان لقطاع الطاقة السعودي داخل NEXIOS. كل البيانات محاكاة
واقعية الطابع (`is_simulation=true`) ومرتبطة بالمناطق الأربع من
`src/lib/regions.ts` (الوسطى · الغربية · الشرقية · الجنوبية).

## ① الامتثال HCIS — `/hcis`
لوحة امتثال للهيئة العليا للأمن الصناعي:

- **نسبة الامتثال** الكلية (دائرة تقدّم) + لكل منطقة + لكل فئة.
- **مصفوفة الامتثال** (الفئة × المنطقة) بألوان الحالة: ممتثل/جزئي/غير ممتثل.
- **سجل الفجوات** بخطورتها وخطط المعالجة (CAP) وعدّاد أيام للموعد (أحمر عند التأخّر).
- **جدول التفتيشات** القادمة والمنفّذة.
- زر **«تقرير جاهزية التفتيش»** → مستند عربي RTL جاهز للطباعة/حفظ PDF
  (ملخّص تنفيذي + نِسب + جدول فجوات + توقيع). اللحظة البيعية ②.

الفئات: الحماية المادية · المراقبة الإلكترونية · القوى الأمنية · إدارة
الطوارئ · أمن المعلومات التشغيلية · التحكم بالدخول. الصياغة عامّة احترافية
لا تنسب نصًّا لأي وثيقة رسمية.

## ② تصاريح العمل الرقمية (PTW) — `/ptw`
دورة حياة كاملة للتصاريح:

- **لوحة اليوم**: ساري الآن · بانتظار موافقة · ينتهي خلال ساعتين · منتهٍ اليوم.
- **بطاقات التصاريح السارية** بألوان أنواعها (عمل ساخن 🔥، مكان مغلق،
  منطقة محظورة، حفر، رفع ثقيل، عزل كهربائي ⚡).
- **إنشاء تصريح**: نموذج خطوات → يُرسل لسلسلة الموافقات
  (مشرف العمل ← مسؤول السلامة ← مسؤول الأمن الصناعي).
- **رمز QR لكل تصريح** → يفتح صفحة تحقّق عامّة `/verify/permit/:id`
  (ساري؟ لمن؟ أين؟ حتى متى؟ الاحتياطات؟) بشارة خضراء/حمراء. اللحظة البيعية ①.
- **تعليق طوارئ** لتصاريح منطقة كاملة خلف **تأكيد بشري إلزامي** (دور admin/manager).

## الأمان
- كل جدول جديد عليه RLS بسياسات صريحة (قراءة: عضو المؤسسة · كتابة: operator+).
- `permit_events` سجل إلحاقي فقط (لا تعديل/حذف).
- سلسلة الموافقات تحترم الأدوار؛ التعليق الطارئ ونداء ARIA له خلف تأكيد بشري.
- صفحة التحقق العامة تقرأ عبر service-role مجموعةً آمنة فقط، مع حدّ معدّل بالـIP.

## ذكاء ARIA
أدوات: `hcis_compliance_status` · `hcis_critical_findings` · `ptw_active_permits`.
أمثلة: «ما نسبة امتثال الغربية؟» · «ما الفجوات الحرجة المتأخرة؟» ·
«كم تصريح عمل ساخن ساري في الشرقية؟».

## البذر
لوحة الأدمن → **«بذر HCIS + التصاريح»** (idempotent) تولّد ~40 بند امتثال +
تقييمات لكل منطقة + فجوات + تفتيشات، و6 أنواع + ~25 تصريحًا بسلاسل موافقات
وأحداث. كلها موسومة `metadata.sim_seed` و`is_simulation=true`.
