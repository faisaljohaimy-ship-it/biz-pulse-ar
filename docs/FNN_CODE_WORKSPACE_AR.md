# مساحة code في FNN

مساحة خاصة بمالك النظام لإعداد ملفات البرمجة ومسودات الأتمتة وحفظ حزمها داخل النظام. لا تحتاج إلى نموذج ذكاء اصطناعي مدفوع.

## الاستخدام

1. سجّل الدخول بحساب المالك، ثم افتح FNN واختر تبويب **code**.
2. سمِّ الحزمة، ثم اختر **إضافة ملفات** أو **ملف جديد**. يمكن اختيار قالب أتمتة جاهز للمراجعة.
3. حرّر مسار الملف ومحتواه. تقبل المساحة ملفات نصية UTF-8: حتى ١٠ ملفات، و٢٥٦ KiB لكل ملف، و١ MiB للمحتوى إجمالًا.
4. راجع نتيجة فحص المسارات والحجم وصيغة JSON. هذا الفحص لا يثبت صحة البرنامج أو أمان تشغيله.
5. اختر **حفظ حزمة خاصة في النظام** لرفع نسخة مستقلة، أو **تنزيل الحزمة** لتصدير المسودة إلى جهازك.
6. لفتح نسخة محفوظة، اختر **تحديث الحزم** ثم **فتح**. تُعرض آخر عشر حزم؛ حفظ التعديلات ينشئ حزمة جديدة ولا يستبدل السابقة.

الحزمة المحفوظة خاصة؛ لا يوجد رابط عام للملفات. عند تعذّر وصول نتيجة الحفظ، حدّث القائمة قبل المحاولة مرة أخرى، لأن الكتابة قد تكون اكتملت بالفعل.

## ماذا تنفّذ المساحة؟

| القدرة                 | السلوك                                                                                         |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| إضافة الملفات والتحرير | نص خام في ذاكرة الجلسة؛ لا تنفيذ ولا معاينة HTML نشطة                                          |
| فحص JSON               | فحص الصيغة فقط، مع التحقق من حدود الملفات ومساراتها                                            |
| قالب الأتمتة           | مسودة مع `enabled: false`؛ لا تُسجَّل في المجدول عند حفظها                                     |
| حفظ الحزمة             | رفع JSON خاملة خاصة إلى مخزن النظام، بعد تحقق المالك وعضوية المؤسسة                            |
| تنزيل الحزمة           | تنزيل JSON تحتوي النصوص للمراجعة؛ لا نشر للموقع                                                |
| أتمتة FNN الحالية      | مستقلة؛ اسأل في تبويب المحادثة عن «حالة أتمتة FNN» أو «مهام أتمتة FNN» لقراءة النتائج المحفوظة |

لا ترفع مفاتيح أو كلمات مرور أو ملفات بيئة. تمنع المساحة مسارات الملفات الحساسة وأنماطًا معروفة من بيانات الاعتماد؛ لا تُعد هذه الفحوص ماسحًا شاملًا للأسرار.

## حدود البرمجة والنشر

الحفظ داخل النظام لا يطبّق الملفات على مصدر التطبيق، ولا يشغّل برنامجًا أو يثبّت مكتبات أو ينشئ أتمتة جديدة. لا يوجد في هذه المساحة اتصال نشر مستقل إلى GitHub أو Vercel، ولا نموذج يولّد الكود. رفع مستندات المعرفة متاح عبر الرابط القائم، وله مسار معالجة مستقل.

فرع المستودع المطلوب اسمه `code`، ويُنشأ من التحديث المراجع. تعطيل نشره الآلي في `vercel.json` يمنع تشغيله بإعدادات بيئة غير مهيأة. تحديث واجهة المساحة يُنشر عبر فرع المعاينة المهيأ؛ تحويل الإنتاج يبقى بعد اختبار دخول المالك والمزامنة النهائية.

## ملاحظات الصيانة

- تُحفظ الحزم في `aria-documents` تحت `<ownerId>/fnn-code/<uuid>.json`، باستعمال جلسة المستخدم وسياسات المخزن الخاصة؛ لا مفتاح إدارة في المتصفح.
- تُعاد مصادقة المالك وعضوية المؤسسة الثابتة عند كل عملية خادم، وتُفحص الحزم المقروءة قبل عرضها.
- لا تدخل الحزم المرفوعة في المستودع العام أو سياق نموذج ذكاء اصطناعي.
- إغلاق الصفحة أو تبديل الحساب يفقد المسودة غير المحفوظة. الملفات المحفوظة تبقى في المخزن.
- التراجع عن واجهة الميزة لا يحذف الحزم، ولا يوقف مراقب التشغيل أو أتمتة التقارير السابقة.
