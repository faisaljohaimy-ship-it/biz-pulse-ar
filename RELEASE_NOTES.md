# NEXIOS AI OS — v1.0.1 remediation release

**Release date:** 2026-07-15  
**Runtime target:** Cloudflare Workers + Supabase

This release turns the supplied archive into a reproducible, verifiable release
candidate. It restores the authenticated boundary, validates bearer tokens,
hardens paid-provider endpoints and public lead forms, removes published npm
vulnerabilities, restores missing assets/PWA files, and makes CI/deployment use
one npm lockfile.

The requested executive artwork is preserved with 44 active controls. Central,
western, eastern, and southern controls use `#3B82F6`, `#22D3EE`, `#22C55E`,
and `#F59E0B` respectively. Selecting a region updates the operating context,
the active icon edges, and the transparent pulsing 3D selector mounted at the
top-left of the application workspace.

The source archive passes lint, TypeScript, Vitest, the production Cloudflare
build, and the production npm advisory audit. Production deployment remains an
operator action because credentials, the target database, migrations, and live
verification evidence are not contained in source control.
