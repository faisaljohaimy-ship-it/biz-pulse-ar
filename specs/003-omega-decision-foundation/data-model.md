# OMEGA data model

- **OmegaAssumptions**: `cameraAvailable:boolean`, `patrolCount:integer 0..12`, `responseMinutes:integer 1..120`, `routeOpen:boolean`, `connectivityAvailable:boolean`. Reject unknown scenario, wrong types, nonfinite/fraction/out-of-range numbers; no implicit coercion to a safe-looking result.
- **World projection**: Small transient graph for one existing scenario using type-compatible entity/relation vocabulary, stable local IDs and fixture evidence. References resolve; projection timestamp is not a measured incident time. No shared server store mutation.
- **Risk hypothesis**: Rule identifier, categorical review-priority interpretation, supporting evidence and assumptions, missing facts and proposed verification. It does not alter the historical event severity or claim calibrated probability/proven root cause.
- **What-if comparison**: Canonical immutable baseline versus validated variant; deterministic explained changes and explicit limits. Bounded dependency tracing defaults to depth3 and validates integer depth0..6 and must terminate on cycles/unknown nodes.
- **Local review state**: Controlled UI acknowledgement/outcome/export eligibility applies only to the exact scenario and assumptions. Input changes invalidate it; reset/scenario switch restores defaults; locale change preserves current semantic values.
- **Report payload**: Optional fifth report argument `{scenarioId, assumptions}`. Rebuild the full canonical fixture/lab rules; reject altered event/severity/evidence, foreign scenario, extra result fields and malformed inputs. Review state is caller supplied; the serializer does not authenticate its history or real actor and supplies no cryptographic signature or durable/tamperproof audit. Preserve safe locale/HTML, `simulated:true`, `operationalApproval:false`, empty executed actions, and no-authority disclosures.
- **Roadmap/evidence**: Exactly 15 owner capabilities; current status working/partial/demo/unavailable is separate from evidence source/date/verification strength. Eight competitor records distinguish documented, announced and inferred claims; unknown does not mean absent.
