# Feature Specification: التوأم المرجعي والفيديو التوضيحي

**Feature Branch**: `feature/sadeed-twin-reference-motion-20261123`

**Created**: 2026-11-23

**Status**: تنفيذ جزئي؛ قبول الإصدار غير مكتمل.

**Input**: تطبيق واجهة التوأم وفق المرفق الجديد، مع فيديو موشن احترافي لنافذة «البث المباشر». طلب المالك الأخير «انشر فورًا بدون CI» يخص هذه المهمة فقط، ولا يغير الحماية أو الصلاحيات أو الميزانيات أو السياسة الدائمة.

## User Scenarios & Testing _(mandatory)_

### User Story 1 — توأم مرجعي تفاعلي (Priority: P1)

يشاهد المستخدم تكوينًا قريبًا من المرجع داخل تجربة سديد للتوأم، ويختار المنطقة والقسم وتفاصيل الأصول والطبقات محليًا، مع فهم واضح أن الأرقام والمشاهد مرجعية.

**Why this priority**: يحول المرجع المرئي إلى تجربة مفهومة قابلة للاستخدام، مع حفظ الفصل عن تشغيل المنشأة الفعلي.

**Independent Test**: تغيير المناطق الأربع والأقسام الخمسة والطبقات والتفاصيل باللمس ولوحة المفاتيح، دون طلب شبكة أو تغيير بيانات.

**Acceptance Scenarios**:

1. **Given** التوأم القائم، **When** يختار المستخدم إحدى المناطق الأربع المعتمدة أو أحد الأقسام الخمسة، **Then** تتغير الحالة المحلية والتفاصيل بوضوح، دون تغيير مصدر تشغيلي.
2. **Given** مؤشرات المرجع، **When** تظهر الأرقام أو «الشمال» في الرسم، **Then** تُوسم الأرقام بأنها محاكاة/مرجعية، ويظهر الشمال كعنصر توضيحي غير متصل؛ لا يُنشأ إقليم تشغيلي خامس.
3. **Given** اللغتان والوضعان والمقاسات الخمسة، **When** يتنقل المستخدم ويفتح التفاصيل ثم يغلقها، **Then** تبقى الواجهة مقروءة دون سكرول أفقي، مع أهداف 44×44 بكسل وتركيز يعود للعنصر المناسب.

### User Story 2 — فيديو توضيحي يدوي (Priority: P1)

يفتح المستخدم نافذة الفيديو بإجراء صريح، فيرى موشن توضيحيًا احترافيًا مرتبطًا بتصميم التوأم، دون اعتباره بث كاميرا حيًا.

**Why this priority**: يضيف الحركة المطلوبة دون تنزيل مبكر أو صوت متداخل أو ادعاء اتصال حي.

**Independent Test**: قبل play لا مصدر فيديو أو طلب بياناته؛ بعده يعمل الملف المحلي المحدد، ويوقفه الإغلاق والتبديل مع حفظ أولوية منسق الصوت القائم.

**Acceptance Scenarios**:

1. **Given** نافذة المرجع المسماة «البث المباشر»، **When** تُعرض للمستخدم، **Then** يرافقها إفصاح AR/EN ظاهر بأن الفيديو توضيحي وليس بثًا حيًا؛ الاسم المرجعي لا يمنح دلالة تشغيلية.
2. **Given** عدم الضغط على play أو تفضيل تقليل الحركة، **When** تفتح الصفحة، **Then** يبقى الملصق ولا يُطلب مصدر الفيديو قبل الإجراء اليدوي.
3. **Given** فيلم يعمل، **When** يُغلق أو يبدأ فيلم آخر أو يغادر المستخدم، **Then** يتوقف السابق وتُنظف الموارد وفق المنسق القائم، دون مشغل أو صوت منافس.
4. **Given** أداة خارجية بلا رصيد كافٍ أو تسعير/استحقاق غير معلوم، **When** تُراجع النتيجة، **Then** تُذكر حالتها صراحة؛ لا يُدعى أنها أنتجت فيلمًا ولا يُنشأ إنفاق إضافي.

### User Story 3 — تسليم صادق بالنطاق الحالي (Priority: P1)

يحصل المالك على نتيجة قابلة للمراجعة، مع حفظ عمل 004 وصورته الزرقاء وفيلميه، ومعرفة ما نشر فعلًا وما بقي معطلًا.

**Why this priority**: طلب السرعة وتجاوز CI لا يحول نتيجة غير مقيسة إلى نجاح أو يغير حماية الإنتاج.

**Independent Test**: مطابقة الأصول والسلوك والميزانيات مع دليل واضح، ثم إثبات معرف/بصمة/رابط الإصدار إن حدث، أو العائق الفعلي.

**Acceptance Scenarios**:

1. **Given** عمل 004 المحفوظ، **When** تضاف واجهة 005، **Then** تبقى الصورة الزرقاء الدقيقة والفيلمان الأصليان دون استبدال أو إعادة ترميز، ولا يُوصف 004 بأنه صدر.
2. **Given** طلب المالك تجاوز CI لهذه المهمة، **When** يقرر مسار التسليم، **Then** يُسجل الاستثناء المحدد مع الحماية الفعلية؛ لا تُعطل workflows أو قواعد الفرع أو الأذونات أو الاحتياطي لتجاوزه.
3. **Given** غياب فيديو نهائي أو تجاوز ميزانية أو عائق قبول، **When** يُكتب التقرير، **Then** يبقى التسليم غير مكتمل ولا تُتوقع بصمة أو QA أورابط/معرف نشر.

### Edge Cases

حالة فارغة/تعذر ملصق أو فيديو، منع play أوترميز غير مدعوم، تقليل الحركة، تضارب الصوت، إغلاق التفاصيل وإعادة التركيز، تبديل اللغة/المنطقة أثناء فتح نافذة، أرقام المرجع التي تشبه حالة حية، ووجود حماية ترفض مسار النشر المطلوب.

## Requirements _(mandatory)_

### Functional Requirements

- **FR-001**: تستلهم الواجهة المرجع المحفوظ دون ادعاء أنه منشأة أو بيانات تشغيلية حقيقية؛ الأرقام الخمسة مرجعية موسومة.
- **FR-002**: تستخدم المناطق الأربع من المرجع الجغرافي القائم، مع خمسة أقسام وظيفية وتفاصيل/طبقات محلية؛ الشمال زخرفي غير تشغيلي فقط.
- **FR-003**: العربية/الإنجليزية و RTL/LTR والوضعان والمقاسات 360/390/430/768/1280، ولوحة المفاتيح و 44×44 بكسل وإعادة التركيز مطلوبة.
- **FR-004**: الفيلم يدوي؛ لا مصدر أو طلب بيانات فيديو قبل play. الملصق وتقليل الحركة والفشل والإيقاف والتنظيف والصوت المنفرد حالات مقبولة ومختبرة.
- **FR-005**: تحافظ الإضافة على منسق الوسائط/الصوت القائم وصورة الرئيسية الزرقاء والفيلمين الأصليين؛ لا APIs أومزود أوكتابة قاعدة أوأوامر أمنية فعلية أو 3D engine جديد.
- **FR-006**: تُنسب نتائج Figma/Higgsfield/HeyGen/التصيير المحلي إلى ما تم فعلًا، مع الرصيد/التكلفة المعلومة؛ لا توليد مدفوع إضافي أوتجاوز ميزانية مفترض.
- **FR-007**: تُثبت جودة التنفيذ والبناء والأداء والحارس والحماية قبل تقرير الجاهزية. طلب تجاوز CI استثناء مهمة 005 فقط، ولا يعني تعديل AGENTS أوالدستور أوتعطيل الحماية الدائمة.

### Key Entities

المرجع وبصمته؛ منطقة معتمدة؛ قسم وتفاصيل محلية؛ مؤشر مرجعي؛ ملصق/فيلم وإفصاح؛ حالة مشغل؛ دليل قبول وإصدار فعلي.

## Success Criteria _(mandatory)_

### Measurable Outcomes

- **SC-001**: تعمل المناطق الأربع والأقسام الخمسة والطبقات/التفاصيل باللغتين محليًا دون شبكة أوتغيير بيانات، مع تمييز الشمال والأرقام المرجعية.
- **SC-002**: لا طلب فيديو قبل play، ولا تداخل صوت عند التبديل والإغلاق؛ الفيلم النهائي والملصق يفحصان فعليًا دون ادعاء بث حي.
- **SC-003**: يجتاز العرض المقاسات الخمسة والوضعين واللغة/اللمس/لوحة المفاتيح وتقليل الحركة دون سكرول أفقي.
- **SC-004**: تبقى السقوف الحالية ثابتة أويسجل قرار مالك محدد لتعديلها؛ لا إعلان نجاح مع تجاوزها. يُذكر النشر الفعلي أو عائقه، دون توقع إيصالات.

## Assumptions

هذه شريحة توأم مرجعي وفيلم توضيحي؛ لا توسع برنامج القدرات الخمس عشرة. رصيد الأداة ليس تفويض إنفاق غير محدود. لا تُنقل موافقة تجاوز CI إلى مهمة أخرى أوإلى قبول دخول/عزل/جهاز لم يُثبت.004 محفوظ محليًا فقط عند `03c3fc25ffe9219d544f93a7442fad29d0e15cbb`؛ ليس دمجًا أوإصدارًا.
