## Summary

ابدأ بطلب A: اعرض الصورة الأصلية كاملة بدل تشغيل الافتتاح في الرئيسية، وانقل إمكانية مشاهدة فيلم الافتتاح الأصلي وفيلم التوأم الأصلي إلى تجربة التوأم القائمة. راجع سلسلة PR453 والفارق الفعلي ثم اجمع الأدلة قبل قرار الإصدار. تراجع B ثبات الدردشة وتفويضها وصحة بياناتها، و C السرعة وإظهار مصدر الإجابة والعمل الفعلي، و D التكاملات والقدرات المتقدمة والتقييم. لا يُفترض تنفيذ كل بند في الدفعة الأولى. أقر root ضمن C واجهة شفافية صغيرة من metadata القائمة فقط، دون استدعاء أو قدرة تشغيلية جديدة؛ تحفظ حالات النطاق/الحداثة/المعتمد/الإيصال المجهولة صراحة.

## Technical Context

- **Language/Version**: TypeScript 5.8 و React 19 ضمن التطبيق القائم؛ لا اعتماد تشغيل جديد.
- **Primary Dependencies**: TanStack Router/Start و i18n والتوكنات والمشغل الحالي وحدود الصوت المشتركة.
- **Storage**: ملفات وسائط قائمة وصورة المالك المرفقة؛ لا قاعدة أو جداول أو بذر بيانات. الأصل المؤرشف في `docs/design/reference/command-room-owner-2026-11-23.jpg` لا يُخدم من public. نسختا العرض في `public/home/command-room/command-room-640.webp` و`command-room-1280.webp`، مع `manifest.json` والسكربت `scripts/prepare-command-room.py`.
- **Image input**: JPEG ‏1280×698؛ SHA-256 `1008e89f8ef301f286dd1448ecfd6bc1805e91547c66a491ee99626fab8b574a`. تصغير وترميز فقط؛ لا قص أو توليد أو تغيير للمشهد.
- **Media**: فيلم الافتتاح القائم، 26 ثانية عند 0.5×؛ فيلم التوأم، 56 ثانية عند 1×. التحقق من ملفات MP4/WebM ودرجات العرض وبصماتها من سجل الأصول؛ اختلاف الترميز ليس اختلاف المحتوى.
- **Testing**: Vitest للقرارات والتنظيف والعقود، واختبارات المتصفح للحركة/الصوت/التحميل؛ دخول فعلي مصرح به؛ iPhone Safari فعلي منفصل عن WebKit. الأدلة الناقصة لا تُستبدل بمحاكاة.
- **Target Platform**: الويب باللغتين والوضعين، المقاسات الخمسة، الحاسوب والهاتف؛ Safari على iPhone شرط قبول جهاز مستقل.
- **Project Type**: تعديل محدود في واجهة التطبيق القائم وتدقيق مساراته؛ لا مشروع أو مسار بديل.
- **Performance Goals**: الميزانيات الحالية ثابتة. آخر نتيجة تاريخية لـ 003 تركت 213.8 بايت JS و 3,863 بايت CSS؛ ليست خط أساس مقيسًا لهذه الدفعة. يلزم قياس جديد، والوسائط تُحمّل عند الحاجة دون تنزيل الفيلمين معًا تلقائيًا.
- **Constraints**: لا تعديل لـ Vite أو regions أو Nusuk أو المصادقة/RLS؛ لا مفاتيح أو بيانات إنتاج أو تشغيل أمني أو تفعيل مزود/راية/إنفاق. لا تغيير للتقارير السابقة أو AGENTS ضمن ملكية هذا الوكيل.
- **Scale/Scope**: A أولًا؛ توثق مصفوفة القدرات الاثنتي عشرة والتكاملات في B–D بصدق، وتضاف الإصلاحات بعد إعادة العطل وتحديد أثرها.

## Delivery Sequence

1. ثبّت أصل المرفق والبصمات وقائمة الملفات؛ راجع PR453 وسلسلة main والفيلمَين قبل التنفيذ.
2. نفّذ الصورة والمعرض في ملفات مستقلة؛ اختبر صفر طلبات فيديو قبل تشغيل المعرض صراحة، بما يشمل خلفية `SystemChrome` المستقلة، وتنظيف التبديل وموانع الحركة والصوت والشبكة.
3. وثّق تدقيق B–D؛ أدخل الإصلاحات المحدودة المثبتة فقط، ولا تفعّل تكاملًا أو مزودًا دون شروطه.
4. نفّذ بوابات الجودة والقبول الفعلي، واطلب تصريح الحارس. غياب الحساب أو الجهاز عائق قبول؛ لا يختفي بمرور الوقت أو عرض النموذج.
5. سجّل دورة نشر جديدة قبل أول دفع بعد إغلاق الدورة السابقة، واحسب كل الحالات مع الاحتياطي. لا تفترض عددًا أو إعداد CD غير مقيس.
6. اتبع سياسة PR/CI والإصدار المرحلي والترقية والتحقق؛ سجّل النتائج الحقيقية أو العائق. البصمات والمعرفات اللاحقة للالتزام في PR والتقرير الخارجي لتجنب التزام توثيقي إضافي.
