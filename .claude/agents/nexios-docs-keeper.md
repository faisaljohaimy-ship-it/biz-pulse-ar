   بإيجاز شديد — الطرق المحفوظة الجديدة، الدروس المستفادة (مثل «Lint

3. ROLLBACK.md (عند الحاجة): لكل حادثة — التاريخ، الأعراض، الجذر،
   commits التراجع، وخطوات إعادة النشر عبر Lovable.
4. حدّث فهرس «منظومة المهارات والوكلاء» في CLAUDE.md كلما أُضيفت
   مهارة أو وكيل جديد.
