# LLM Wiki — ويكي معرفة حيّة

- **المصدر:** `github.com/nvk/llm-wiki`.
- **التفعيل:** مُسجَّل سوقه في `.claude/settings.json` باسم `llm-wiki`؛ التثبيت
  `claude plugin install wiki@llm-wiki` (أو `claude --skill llm-wiki`). بنيته
  محور‑وأفرع: سجلّ مركزيّ يشير إلى ويكيات موضوعية معزولة.
- **المفاتيح/الشبكة:** يعمل مع مزوّد النموذج المهيّأ؛ لا سرّ إضافيّ.

## متى تستعمله

لتركيز معرفة المشروع (المعماريّة، الكتيّبات، قرارات المالك المؤرّخة) في سطح
قابل للاستعلام. لا يُغني عن مصادر الحقيقة الرسمية في المستودع
(`CLAUDE.md`، الدستور، `docs/**`) — يبني فوقها لا يستبدلها، ولا يخترع أرقامًا.

## الحوكمة

الدستور يسود، ووثائق الحوكمة في المستودع تبقى مصدر الحقيقة. لا دفع قبل تصريح
`nexios-qa-guardian`. أداة زمن تطوير لا تُستدعى من الإنتاج.
