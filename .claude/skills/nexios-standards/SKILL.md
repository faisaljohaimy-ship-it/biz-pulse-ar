# NEXIOS Standards — الدستور التشغيلي

## اللغة والاتجاه
- **عربي أولًا، RTL إلزامي**: كل صفحة `dir="rtl"`؛ الإنجليزية ثانوية.
- **ثنائية اللغة في البيانات**: كل كيان معروض يحمل `name_ar` و`name_en`
  (انظر `src/lib/regions.ts`، جداول `hcis_directives`, `sec_sites`).
- نصوص الحالة/الأخطاء بالعربية دائمًا — لا تُظهر أبدًا عبارات مصادقة خام
  (أي `/authenticat|unauthor|token/i` تُستبدل برسالة عربية محايدة).

## الهوية البصرية
- طابع سينمائي navy داكن مع لمسات زمردية/سماوية (انظر `src/styles.css`).
- **الألوان الإقليمية الفعلية** — المصدر الوحيد `REGION_ACCENT_HEX` في
  `src/lib/regions.ts`:
  - Central `#3B82F6` · Western `#22D3EE` · Eastern `#22C55E` · Southern `#F59E0B`
  - لا تكتب هذه القيم يدويًا في مكوّن؛ استهلك الخريطة.
- الخط: `--font-arabic: "Cairo", "IBM Plex Sans Arabic", system-ui`.
- المنطقة الافتراضية: `DEFAULT_REGION_ID = "western"`.

## قواعد صلبة
- **`src/lib/regions.ts` هو المرجع الجغرافي الوحيد** — لا قوائم مناطق مكررة،
  ولا بيانات مناطق خارجه إطلاقًا.
- **لا secrets في الكود أو الريبو** — المفاتيح بيئية على الخادم فقط
  (`ELEVENLABS_API_KEY`, `LOVABLE_API_KEY`, …). أي مفتاح في العميل = رفض.
- **لا تعديل على إعدادات vite** (`manualChunks` و`sourcemap: false` تبقى).
- **كل الأرقام المعروضة من Supabase — لا hardcoded**: البيانات الحية أولًا،
  وعند غيابها المحاكاة المرجعية الموسومة `is_simulation = true` بشارة
  ظاهرة (التفصيل في مهارة `nexios-supabase`؛ migrations دائمًا idempotent).
- أي كتابة/طوارئ خلف بوابة تأكيد بشري.
- أهداف اللمس ≥ 44×44px؛ مقاسات الاختبار: 360 / 390 / 430 / 768 / 1280px؛
  RTL بلا قص أفقي — الصفحة لا تسكرول أفقيًا أبدًا.

## الحالات الإلزامية لكل صفحة بيانات (التفصيل في `nexios-ui-patterns`)
- skeleton بمهلة 4 ثوانٍ (التحميل اللانهائي محظور) + حالة فارغة عربية +
  حالة خطأ عربية بزر إعادة محاولة — الثلاث معًا، لا استثناء.

## خطوط حمراء من عقائد شقيقة (ملخص إلزامي)
- **آريا**: صوتها ElevenLabs Layan حصريًا عبر الخادم؛ `speechSynthesis`
  محظور نهائيًا؛ النمط الثنائي display/tts بالتشكيل؛ `aria_knowledge`
  خلف المصادقة دائمًا (التفصيل في `nexios-aria`).
- **نُسك**: منصة مستقلة تُفتح خارجيًا من `platforms.ts` — لا iframe ولا
  proxy ولا لمس (التفصيل في `nexios-hcis-domain`).

## بوابة التحقق قبل أي دفع (بالترتيب، كلها تنجح)
```bash
npx tsc --noEmit          # صفر أخطاء
npx eslint .              # كامل الريبو — صفر أخطاء (التحذيرات مقبولة)
npx vitest run            # كل الاختبارات
npm run build && node scripts/check-performance-budget.mjs
```
- **commit واحد لكل جلسة** برسالة واضحة، ثم دفع إلى `main` والفرع
  المخصص للجلسة إن وُجد.
- الدرس المحفوظ: lint مستهدف لا يكفي — Lint كامل الريبو دائمًا (فشل lint
  يجمّد النشر عبر CI).
