# Graphify — خريطة معرفة للكود

- **المصدر:** `github.com/Graphify-Labs/graphify` (رخصة MIT).
- **التفعيل:** `pip install graphifyy && graphify install` (يضيف مهارة
  `/graphify`). يتطلّب Python ‏3.10+. التحليل محلّي عبر tree-sitter + مسح
  رسم الاستدعاءات؛ الوثائق/الصور تمرّ بالنموذج.
- **المخرجات:** `graphify-out/` فيها `graph.html` و`GRAPH_REPORT.md`
  و`graph.json` — **لا تُدفَع إلى git** (بيانات مشتقّة؛ أضفها إلى تجاهلك المحلّي).
- **المفاتيح/الشبكة:** تحليل الكود محلّي؛ استخراج المفاهيم من الوثائق يستعمل
  مزوّد النموذج المهيّأ.

## متى تستعمله

قبل ميزة تمسّ وحدات متعدّدة، أو لفهم تدفّق عبر `src/lib/**`/`src/routes/**`.
داخليًّا `codebase-onboarding` و`context-budget` يغطّيان جزءًا؛ Graphify أعمق
للرسوم البيانية. لا تثق برقم «كفاءة» تسويقيّ؛ القيمة الفعلية تُقاس لا تُدّعى
(المادة ٢٧).

## الحوكمة

الدستور يسود. مخرجاته لا تدخل git. لا دفع قبل تصريح `nexios-qa-guardian`.
أداة زمن تطوير لا تُستدعى من الإنتاج.
