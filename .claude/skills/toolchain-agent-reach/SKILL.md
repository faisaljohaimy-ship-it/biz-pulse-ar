# Agent Reach — وصول الويب (وراء بوابة المالك)

- **المصدر:** `github.com/Panniantong/agent-reach`.
- **التفعيل (بإذن المالك):** `npx skills add Panniantong/Agent-Reach@agent-reach`
  ثمّ CLI ‏`agent-reach` (و`agent-reach doctor` للفحص). الاعتمادات تُحفَظ محلّيًّا
  في `~/.agent-reach/config.yaml` بصلاحيات 600.

## قرار الحوكمة (لا تفعيل تلقائيّ)

يفتح خروجًا شبكيًّا واسعًا وكشطًا لمنصّات تتطلّب تسجيل دخول بكوكيز — خطر أعلى
يناقض انضباط الخروج. لذلك:

- **غير مُفعَّل افتراضيًّا**، ولا يُضاف إلى `.mcp.json`.
- يُشغَّل بإذن المالك الصريح لمهمّة محدّدة، **بحسابات منفصلة (burner)** حيث يلزم
  تسجيل الدخول، **ولا يلمس أسرار أو حسابات الإنتاج**.
- للبحث العامّ البسيط، تكفي أدوات `WebSearch`/`WebFetch` المدمجة غالبًا؛ لا تلجأ
  إلى Agent Reach إلا حين تعجز هذه.

## الحوكمة

الدستور يسود. لا أسرار إنتاج ولا حساباتها. بإذن صريح فقط. لا دفع قبل تصريح
`nexios-qa-guardian`. أداة زمن تطوير لا تُستدعى من الإنتاج.
