# طبقة أدوات سَدِيد — الفهرس المعتمد

أحدث إضافات/مهارات/مخدّمات MCP الخارجية، مُودَعة في المستودع ومحكومة بعقيدة
`CLAUDE.md` ودستور `SADEED_CONSTITUTION.md`. التفصيل الكامل (المصدر، الأمر،
المفاتيح، نطاق الشبكة، حكم التوافق مع الدستور) في
`docs/tooling/SADEED_TOOLCHAIN.md`.

## القاعدة الحاكمة (تسبق كل أداة)

1. **الدستور يسود.** عند أي تعارض بين سلوك أداة وبين `CLAUDE.md` /
   `SADEED_CONSTITUTION.md`، يسود الدستور. خصوصًا: العربية أولًا/RTL، خطوط
   IBM Plex Sans Arabic/Tajawal/Cairo ولوحة navy/emerald، `regions.ts` المرجع
   الجغرافي الوحيد، صوت سَدِيد الذكوري حصريًّا، ومنع `speechSynthesis`.
2. **لا سرّ في العميل أو المستودع.** كل مفاتيح الأدوات تُضبط في البيئة بأسمائها
   فقط (`.env.example` يسرد الأسماء). أي أداة بلا مفتاح تبقى «مهيّأة غير مفعّلة».
3. **بوابة الجودة قبل أي دفع.** `nexios-standards` بداية الجلسة، و`nexios-qa-guardian`
   يصرّح قبل أي commit يُدفع. الأدوات لا تتجاوز البوابة ولا تُفعَّل داخل مسار الإنتاج.
4. **أدوات التطوير لا تُستدعى من الإنتاج.** هذه الطبقة لزمن التطوير داخل Claude Code،
   لا سطح تشغيل. لا تضيف اعتمادًا إنتاجيًّا جديدًا بسببها.

## تنبيهان بقرار حوكمة

- **«Awesome Free LLM APIs» مرجع فقط، لا يُوصَل بمسار التشغيل.** موجّه مزوّدات
  متعدّد يناقض حصرية المزوّد (Gemini مباشرةً + احتياطي واحد) وقاعدة «لا مفاتيح في
  الريبو». يبقى وثيقةً يُستأنس بها، لا راية تشغيل.
- **«Agent Reach» وراء بوابة المالك.** يفتح خروجًا واسعًا للويب والمنصّات بكوكيز
  حسابات. لا يُفعَّل تلقائيًّا؛ يُشغَّل بإذن صريح وبحسابات منفصلة، ولا يلمس أسرار
  الإنتاج (تفصيل في مهارته).

ابدأ من `docs/tooling/SADEED_TOOLCHAIN.md` لخطوات التفعيل والمفاتيح لكل أداة.
