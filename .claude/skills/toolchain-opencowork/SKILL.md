# OpenCowork — ما فُحص، ولماذا لم يُثبَّت

**الحكم (مثبَّت في `scripts/toolchain/tools.lock.json`: `status: not-installed`):** لم يُركَّب أيّ
مشروع بهذا الاسم في المستودع أو في إعدادات Claude Code أو على أي جهاز. فحصٌ للقراءة فقط
(٢٠٢٦/١١/٠٤: `npm view` و`npm pack --ignore-scripts` وقراءة الملفات المستخرجة و
`raw.githubusercontent.com`؛ لم يُثبَّت شيء ولم يُنفَّذ). **وصحّحتُ به حكمًا أوّل كان خاطئًا:**
القول «لا CLI ولا MCP» صحيح لمشاريع منها ولا يصحّ على المشروع الذي له CLI.

## لماذا لم يُثبَّت حتى الذي له CLI (`@aidotnet/opencowork@1.4.0`)

1. **متجمّد:** آخر إصدار npm بتاريخ ٢٠٢٦/٠٩/٠٣، وتحوّل المستودع بعدها إلى منتج آخر (NextCoWork). الاستنتاج
   «مهجور» **استنتاجي** من غياب إصدار لشهرين، لا خبر منشور.
2. **عامله الأصلي مغلق المصدر** ويحمل أدوات shell وملفات وويب وSSH؛ لم يُفحص ثنائيّه ولا عزله.
3. **مفاتيح المزوّد تُخزَّن نصًّا** في `~/.open-cowork/`، و**البيئة كاملةً تُمرَّر إلى العامل**: يناقض «لا أسرار
   تتسرّب» التي تفرضها بوابة OpenCode.
4. **الحجم والتنفيذ:** أرشيف ١٤٨٫٥ ميغابايت مضغوطًا (٥٤٥ بعد الفك) بثنائيات ست منصّات وسكربت `postinstall`.
5. **لا MCP ولا ACP** (مكتبة MCP فيه عميلٌ فقط)، فلا يُستهلك أداةً من Claude Code إلا عبر Bash كعملية فرعية.
6. **الترخيص متعارض:** npm تقول MIT وREADME المستودع Apache-2.0.
7. وإضافة بوابة ثانية لثنائي مغلق غير مفحوص خارج التناسب مع الحاجة، والحاجة تؤديها OpenCode.

## إن أراد المالك واحدًا منها (قراره وحده — المواد ٨ و١٩ و٢٤)

حدّد أيّها تقصد أولًا. وللتجربة: **جهاز أو آلة افتراضية منفصلة بلا مفاتيح سَدِيد ولا بيانات الإنتاج**،
ومن المصدر الرسمي حصرًا، مع حساب بصمة الملف المنزَّل وحفظها، ومجلد عمل فارغ، ونموذج محلي أو مفتاح
مخصَّص قابل للإلغاء. لا يُدخَل أي مفتاح من هذا المشروع. وإن طلب المالك إدماج `@aidotnet/opencowork`
كمفوَّض ثانٍ فيُبنى له باب مستقل بنفس ضوابط `delegate.mjs` (بيئة مقلَّمة، مسارات ضيّقة، رقعة لا تُطبَّق)
**بعد** فحص عامله الأصلي؛ ولم يُفعل.
