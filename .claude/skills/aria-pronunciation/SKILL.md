# نطق آريا — المادة ٢٢ §٥

طبقة TTS (ElevenLabs Layan حصرًا) تنطق اللاتيني والرموز عربيةً صحيحة.
النص المعروض يبقى بالصيغة اللاتينية الكنسية؛ **النطق فقط** يُحوَّل.

## أمثلة القاعدة
| مكتوب | منطوق |
|---|---|
| SEC-18 | سِك ثمانية عشر |
| SAF-07 | ساف سبعة |
| PTW | تصريح العمل |
| HCIS | الهيئة العليا للأمن الصناعي |
| CCTV | كاميرات المراقبة |
| NEXIOS · ARIA | نكسيوس · آريا |

## التنفيذ (مصدر واحد)
- `applyAriaPronunciation(text)` + `arabicCardinal(n)` في
  `src/lib/aria/pronunciation.ts`.
- يُطبَّق داخل `toAriaSpeechText` في `reply-modality.ts` — الحارس النهائي
  للعميل قبل إرسال النص إلى `/api/aria/tts`.
- التوسيع بسطر واحد: أضِف زوجًا إلى `TERMS`، أو وسّع نمط SEC/SAF.
  `arabicCardinal` يغطي ٠–٩٩ (كل رموز التوجيهات).

## ثوابت
- لا استبدال مزوّد ولا صوت غير ليان لآريا.
- `speechSynthesis` محظور — النطق كله خادمي.

## قبل الدفع
`pronunciation.test.ts` أخضر: SEC‑18/SAF‑07/الرقم/القاموس/النثر العربي
غير الممسوس.
