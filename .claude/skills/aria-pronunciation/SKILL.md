# نطق سَدِيد — المادة ٢٢ §٥

طبقة TTS (صوت سَدِيد الذكوري عبر ElevenLabs حصرًا) تنطق اللاتيني والرموز عربيةً صحيحة.
النص المعروض يبقى بالصيغة اللاتينية الكنسية؛ **النطق فقط** يُحوَّل.

## أمثلة القاعدة

| مكتوب         | منطوق                       |
| ------------- | --------------------------- |
| SEC-18        | سِك ثمانية عشر              |
| SAF-07        | ساف سبعة                    |
| PTW           | تصريح العمل                 |
| HCIS          | الهيئة العليا للأمن الصناعي |
| CCTV          | كاميرات المراقبة            |
| NEXIOS · FINN | نكسيوس · فِنّ               |

> **السطر الأخير قاعدة نطق لنص محفوظ، لا اسم المنتج ولا اسم المساعد.**
> الاسمان اليوم **سَدِيد / SADEED**؛ ومدخلا `NEXIOS` و`FINN` باقيان في
> `pronunciation.ts` لأن صفوفًا قديمة ما تزال تحمل التسميتين المسحوبتين —
> حذفهما يجعل سَدِيد يتهجّاهما حرفًا حرفًا بدل أن يمرّهما كلمةً واحدة.
> لا يوجد اليوم مدخل نطق لـ«سَدِيد» (الكلمة عربية أصلًا فلا تحتاج تحويلًا).

## التنفيذ (مصدر واحد)

- `applyFinnPronunciation(text)` + `arabicCardinal(n)` في
  `src/lib/finn/pronunciation.ts`.
- يُطبَّق داخل `toFinnSpeechText` في `reply-modality.ts` — الحارس النهائي
  للعميل قبل إرسال النص إلى `/api/finn/tts`.
- التوسيع بسطر واحد: أضِف زوجًا إلى `TERMS`، أو وسّع نمط SEC/SAF.
  `arabicCardinal` يغطي ٠–٩٩ (كل رموز التوجيهات).

## ثوابت

- لا استبدال مزوّد ولا صوت غير صوت سَدِيد الذكوري.
- `speechSynthesis` محظور — النطق كله خادمي.

## قبل الدفع

`pronunciation.test.ts` أخضر: SEC‑18/SAF‑07/الرقم/القاموس/النثر العربي
غير الممسوس.
