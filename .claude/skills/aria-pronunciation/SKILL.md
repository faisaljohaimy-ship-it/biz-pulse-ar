# نطق سَدِيد — المادة ٢٢ §٥

طبقة TTS (صوت سَدِيد الذكوري عبر ElevenLabs حصرًا) تنطق اللاتيني والرموز عربيةً صحيحة.
النص المعروض يبقى بالصيغة اللاتينية الكنسية؛ **النطق فقط** يُحوَّل.

## أمثلة القاعدة

| مكتوب  | منطوق                       |
| ------ | --------------------------- |
| SEC-18 | سِك ثمانية عشر              |
| SAF-07 | ساف سبعة                    |
| PTW    | تصريح العمل                 |
| HCIS   | الهيئة العليا للأمن الصناعي |
| CCTV   | كاميرات المراقبة            |
| SADEED | سَدِيد                      |
| FINN   | سَدِيد                      |
| NEXIOS | المنصة                      |

> **السطران الأخيران قاعدتا نطق لنصٍّ محفوظ، لا اسمَي عرض.** الاسم اليوم
> **سَدِيد / SADEED** للمنتج والمساعد معًا؛ ومدخلا `NEXIOS` و`FINN` باقيان
> في `pronunciation.ts` لأن صفوفًا قديمة ما تزال تحمل التسميتين
> المسحوبتين — وحذفهما يجعل سَدِيد يتهجّاهما حرفًا حرفًا («إف-آي-إن-إن»)
> بدل أن يمرّهما كلمةً واحدة. ولذلك **لا يُنطق أيٌّ منهما باسمه القديم**:
> `FINN` يُنطق «سَدِيد» و`NEXIOS` يُنطق «المنصة»، فتُغلق آخر قناة يصل بها
> الاسم المسحوب إلى مكبّر الصوت.

## التنفيذ (مصدر واحد)

- `applySadeedPronunciation(text)` + `arabicCardinal(n)` في
  `src/lib/sadeed/pronunciation.ts`.
- يُطبَّق داخل `toSadeedSpeechText` في `reply-modality.ts` — الحارس النهائي
  للعميل قبل إرسال النص إلى `/api/sadeed/tts` (وبديله العام
  `/api/public/sadeed-tts` عند 401/403).
- التوسيع بسطر واحد: أضِف زوجًا إلى `TERMS`، أو وسّع نمط SEC/SAF.
  `arabicCardinal` يغطي ٠–٩٩ (كل رموز التوجيهات).

## ثوابت

- لا استبدال مزوّد ولا صوت غير صوت سَدِيد الذكوري.
- `speechSynthesis` محظور — النطق كله خادمي.
