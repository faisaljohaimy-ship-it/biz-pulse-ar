# REA — فهم وإعادة بناء

**نطاق مشروع:** تحليل ما يملك المالك حقّ تحليله (تطبيقاته، أو مصادر مفتوحة/مرخّصة
بما يسمح). ليس لتجاوز حماية أو انتهاك ترخيص طرف آخر.

- **المصدر:** `github.com/morluto/rea` (رخصة MIT) — توزيع npm `rea-agents`.
- **التفعيل:** `npm i -g rea-agents && rea setup` (يسجّل مخدّم MCP وتعليمات سير
  العمل، وينسخ الإعداد احتياطيًّا أولًا). يدعم Claude Code وأدوات أخرى.
- **المفاتيح/الشبكة:** يعمل محلّيًّا مع مزوّد النموذج المهيّأ؛ أدواته تفحص ثنائيّات
  وحزمًا محلّية. غير مُضاف إلى `.mcp.json` لأنّه يتطلّب تثبيتًا عامًّا أولًا.

## متى تستعمله

لفهم نمط/سلوك ميزة ثم بناء مكافئ **أصيل** داخل معمارية سَدِيد (لا نسخ لصق). المخرج
يمرّ البوابة والهوية والحالات الإلزامية كأيّ كود جديد.

## الحوكمة

الدستور يسود. استعمال مشروع ضمن حقوق المالك. لا دفع قبل تصريح
`nexios-qa-guardian`. أداة زمن تطوير لا تُستدعى من الإنتاج.
