# Email Sequence Writer

Design and write email sequences where every email has one job, and the sequence has one measurable goal.

## When to trigger
- "Write an onboarding / welcome / launch / win-back sequence"
- Drip campaigns, trial-conversion flows, product-update announcements
- Improving an existing sequence

## Process
1. **Pin the goal**: one metric the sequence moves (activation, first purchase, reply, reactivation). Ask once if unclear.
2. **Map the sequence**: for each email define — trigger/day, job of this email, primary CTA. Typical shapes:
   - Onboarding: welcome → first value → key feature → social proof → nudge (5 emails / 7–10 days)
   - Win-back: reminder → value recap → incentive → last call (4 emails)
3. **Write each email**:
   - 2–3 subject line options (curiosity / clarity / urgency — never clickbait)
   - Preview text that extends, not repeats, the subject
   - Body: 50–150 words, one idea, one CTA. Short paragraphs, no walls of text.
   - CTA button label in action voice ("Start your first project", not "Click here")
4. **Voice**: match the product's register; write to one person ("you"), never "our valued users".
5. **Deliver as a table first** (email #, day, subject, goal, CTA) then full copy per email.

## Rules
- One CTA per email. Secondary links only in P.S. if truly needed.
- Personalization tokens marked clearly: `{{first_name}}` with a fallback noted.
- Respect unsubscribe/compliance basics; no manipulative false-urgency.
- Localize on request (pairs with content-localizer for Arabic sequences).

## Quality bar
Each email can be judged alone ("would a busy person act on this?") and the sequence reads as one coherent conversation, not five disconnected blasts.
