# ARIA IMPACT PRIORITY DIRECTIVE v1.0.0 — Supreme Executive Law

## Absolute Invariants
1. Sequential phases 1→9. Never skip.
2. Production quality only — no placeholders/mocks/simulated APIs.
3. Every metric/status/badge evidence-gated via `<EvidenceBadge>` (FR-19).
4. Bilingual AR/EN + RTL on every user-facing surface.
5. Self-aware · self-healing · self-evolving (OBSERVE → ANALYZE → PROPOSE → EXECUTE → VERIFY → AUDIT).
6. Definition of Done = all 9 phases complete AND Final Validation green.

## The Nine Phases
1. **ARIA Core** — Brain · Voice · Avatar · Runtime · Memory · Reasoning · Context · Lip Sync · Arabic · Personality.
2. **Executive Execution** — Task/Action Planning · Approval · Timeline · Progress · Verification · Recommendations · Audit.
3. **Live Demonstration** — Live Reasoning · Thinking Anim · Decision Pipeline · Execution Flow · Status · Timeline · Presentation.
4. **Command Center** — KPIs · Health · Runtime · Operations · Risk · Confidence · Recommendations · Reports · Dashboard.
5. **Enterprise Memory** — Persistent · Semantic · Organizational · Conversation · Executive · Historical · Retrieval.
6. **Multi-Agent Intelligence** — Orchestrator · Specialized Agents · Collaboration · Parallel · Aggregation · Conflict Resolution · Shared Context.
7. **Digital Twin** — Live Twin · Assets · Facilities · Incidents · Patrols · Map · Predictive.
8. **Performance & Stability** — Rendering · Runtime · Bundle · DB · APIs · React · TS · Memory · Mobile.
9. **Executive Experience** — Storytelling · Journey · Presentation · Narrative · Motion · Animation · UX · UI.

## Final Validation (auto-run before "done")
Architecture · Runtime · Performance · TypeScript · Build · Accessibility · Responsive · Regression · Production.

## Enforcement
- Every ARIA entry-point wraps its system prompt via `withAriaSupremeLaw` and includes `ARIA_IMPACT_DIRECTIVE`.
- Self-evolution cycles persist to `aria_evolution_cycles`; high-confidence proposals promote to `aria_improvement_proposals`.
- Any surface violating an invariant is treated as a P0 regression.

**How to apply:** cite this directive when planning multi-phase work. Complete the current phase's exit gate before moving on. Never claim completion without running Final Validation.
