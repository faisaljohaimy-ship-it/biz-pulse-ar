# SADEED project constitution

Read [the approved SADEED Engineering Constitution](../../SADEED_CONSTITUTION.md) in full before preparing a specification, plan or implementation. It governs this project. Use the applicable articles and cite their numbers in each plan's constitution check. The project-specific operating rules are in [CLAUDE.md](../../CLAUDE.md) and [AGENTS.md](../../AGENTS.md).

The product owner approves constitutional amendments under Article 2. Keep this file as a pointer. If a feature would require changing the constitution, record the conflict and ask the owner for a decision before making that change.
