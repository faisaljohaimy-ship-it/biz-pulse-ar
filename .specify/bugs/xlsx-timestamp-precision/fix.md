# إصلاح عرض وقت Excel

يقرّب قارئ الاستيراد وقت الخلية إلى أقرب ثانية قبل فصل أجزاء التاريخ والساعة بتوقيت UTC. ويحدد ما إذا كانت الخلية تحتوي وقتًا فقط قبل التقريب، حتى لا يضيف تاريخًا عند عبور منتصف الليل. يكتب مولّد الاختبارات التواريخ بصيغة UTC لضمان ثبات ساعة المصنّف الاصطناعي عند تشغيل الاختبارات في الرياض.

أُضيفت ثلاث حالات اختبار عند مدخل الاستيراد الفعلي تغطي تقويمي المصنّف، وحدّي التقريب، والانتقال إلى اليوم التالي، والوقت المجرد. [التقييم ومعايير القبول](assessment.md)
