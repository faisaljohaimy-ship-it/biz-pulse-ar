# إصلاح تنسيق الملفات المستوردة

أُعيدت نسختا مهارات Claude Code وCodex، وأوامر الإضافتين وقوالب Spec Kit، من نسخة التثبيت التي سبقت التنسيق الآلي. أضيفت أنماط محددة إلى `.prettierignore` لحماية الملفات المستوردة. يظل تنسيق مواصفات الفريق وتقارير الأعطال والقوالب التي يخصصها الفريق متاحًا.

مرجع النطاق والدليل الأولي في [التقييم](assessment.md).
