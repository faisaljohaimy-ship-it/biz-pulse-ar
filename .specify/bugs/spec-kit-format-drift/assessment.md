# تقييم تغيّر ملفات Spec Kit بعد الدمج

**الحكم:** خلل مؤكد، متوسط الأثر. بعد الدمج الأول شغّل GitHub منسّق المستودع على الملفات المستوردة. عند الإصدار `adc7fc6` أعاد `specify integration status --json` تحذيرًا عن 22 ملفًا تغيّر محتواها عن سجل التثبيت. تأثر تسعة ملفات من كل وكيل وأربعة قوالب مشتركة. يشمل أثر المنسّق ملفات إضافية خارج فحص البصمات، منها أوامر إضافتي الأعطال وتقييم الأفكار.

**معيار القبول:** يبقى محتوى المهارات والقوالب والإضافات مطابقًا للإصدار المثبّت بعد تشغيل `npm run format`، ويكتشف كلا الوكيلين المهارات السبع عشرة. يستمر المنسّق في شمول تقارير الأعطال والمواصفات التي يكتبها الفريق.

**نطاق الإصلاح:** استعادة ملفات الحزمة المولّدة من `ebf1d02` واستثناؤها بدقة في `.prettierignore`. تحفظ ملفات المواصفات والقرارات البشرية منفصلة عن الحزمة وفق المادتين 2 و35 من دستور سديد.
