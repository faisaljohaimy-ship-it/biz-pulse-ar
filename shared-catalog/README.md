# Global AI Catalog

178,964 searchable metadata records as of 2026-11-24. The archive contains 168,410 models, 314 skills, 1,500 MCP servers and 8,740 Homebrew software records. Source URLs are included per row. The recent-model and SWE-bench Verified tables are supplementary and excluded from the count.

Download global.zip and search.py into one folder, then run:

```sh
python3 search.py whisper --type model --limit 5
python3 search.py playwright --limit 5
```

Search reads local CSV metadata. Nothing in the archive is automatically installed or executed. Search results do not establish that a third-party service is available or that a model is authorized for a project.

Sources: Hugging Face Hub, Homebrew Formulae, official MCP Registry, public skill repositories, and SWE-bench leaderboards.
