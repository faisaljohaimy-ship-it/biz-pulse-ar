# NEXIOS AI OS

منصة ذكاء تنفيذي ثنائية اللغة، تتضمن مركز قيادة تفاعليًا، آريا، طبقة
صلاحيات متعددة المستأجرين، وتكاملات مؤسسية قابلة للتهيئة.

تدعم آريا المحادثة الصوتية بصوتها الموحّد، الأسئلة النصية، تحليل الصور
والفيديو والصوت والمستندات، وإرسال البريد وSMS عبر مزوّدات مؤسسية تُضبط من
متغيّرات البيئة. الإرسال الخارجي محصور بالحسابات الإدارية المصرّح لها، ويمر
دائماً عبر معاينة كاملة وإقرار بشري ورمز اعتماد قصير الصلاحية قبل إرسال وحيد،
ثم تُحدّث حالة التسليم عبر Webhook موقّع.

يمكن للزائر مشاهدة العرض التنفيذي كاملاً دون اسم مستخدم أو كلمة مرور. لا تظهر
حقول الدخول إلا بعد إقرار صريح بالانتقال من العرض المفتوح إلى مرحلة التفعيل؛
ولا يمنح هذا الإقرار أي صلاحية داخل النظام.

يتضمن المسار `/executive-bridge` إيجازاً قيادياً تفاعلياً من سبعة فصول بصوت
آريا الموحّد. يبدأ الصوت بعد ضغط المستخدم، ويعرض حالة التحضير والتشغيل والخطأ
بوضوح، ولا يستبدل صوت آريا بصوت متصفح آلي عند غياب إعداد ElevenLabs.

## المتطلبات

- Node.js 22 أو 24
- npm 10 أو أحدث
- مشروع Supabase عند تشغيل الوظائف الحية

## التشغيل المحلي

```bash
cp .env.example .env.local
npm ci
npm run dev
```

املأ فقط القيم المطلوبة في `.env.local`. لا تُودع مفاتيح الإنتاج أو
`SUPABASE_SERVICE_ROLE_KEY` في المستودع.

لمعاينة حزمة Cloudflare بعد بنائها، شغّل `npm run build` ثم
`npm run preview`. يستخدم أمر المعاينة إعداد Worker الناتج نفسه بدل خادم Vite
العام.

## بوابة الإصدار

```bash
npm run check
npm audit --omit=dev
```

تجمع `npm run check` بين ESLint، فحص TypeScript، اختبارات Vitest، وبناء
الإنتاج. اختبارات E2E التي تعتمد على Supabase تُشغّل عبر `npm run test:e2e`
بعد توفير بيانات بيئة الاختبار.

## النشر

Cloudflare Workers هو هدف الإنتاج الأساسي. راجع [DEPLOYMENT.md](DEPLOYMENT.md)
لأسماء الأسرار، تطبيق ترحيلات Supabase، خطوات الإطلاق، والتراجع. يوجد
`vercel.json` كمسار يدوي اختياري فقط.
