# تركيب حزمة السكلز في NEXIOS

## 1. نسخة احتياطية وفرع منفصل

نفّذ الدمج في فرع مراجعة، وخذ نسخة احتياطية من قاعدة البيانات. لا تطبق مباشرة على الإنتاج.

## 2. أضف ملفات السكلز

انسخ محتوى `skills/` إلى:

```text
.agents/skills/
```

المعرّفات تبدأ بـ `nx-` لتجنب التعارض مع السكلز الحالية.

## 3. طبّق سجل قاعدة البيانات

راجع ثم طبّق:

```text
db/20260724_nexios_modern_skills.sql
```

ينشئ الملف:

- `skill_registry`
- `organization_skill_settings`
- سياسات RLS للقراءة والإدارة
- 144 سجلًا بحالة `enabled = false`

## 4. اربط المحمّل بالـ runtime

انقل `src/nexios-skill-loader.ts` إلى طبقة server داخل NEXIOS. استخدم `loadEnabledSkills` لاسترجاع السكلز المفعّلة للمؤسسة، و`rankSkills` لاختيار المرشحين، ثم حمّل تعليمات السكلز المختارة فقط.

لا تعتمد على القراءة الديناميكية لنظام الملفات في Cloudflare Workers؛ استخدم قاعدة البيانات أو Registry مولّدًا وقت البناء.

## 5. فعّل لكل مؤسسة

أضف سجلات صريحة إلى `organization_skill_settings` بعد الاختبارات. لا تستخدم تفعيلًا شاملًا تلقائيًا.

## 6. بوابة القبول

- تحقق من عدم وجود تعارض أسماء.
- اختبر العزل بين مؤسستين على الأقل.
- اختبر أن السكلز لا تستدعي أداة خارج allowlist.
- اختبر التوقف عند نقص الدليل.
- اختبر أن كل write أو action يطلب موافقة بشرية.
- قِس الجودة، grounding، زمن الاستجابة، والتكلفة.
- فعّل تدريجيًا مع rollback واضح.
